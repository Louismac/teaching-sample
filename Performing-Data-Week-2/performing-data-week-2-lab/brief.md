# Example Briefs 

← [Lab guide](README.md) · [Week 2 overview](../README.md)

Pre-generate instructions / script and perform, or generate live during performance!

## Constrained Vocabulary 

* Generate a 2-minute monologue where the character can only use words from a specific category (emotions, colors, foods, etc.)

## One Sentence, Infinite Variations

* Give LLM a single sentence to expand into a scene, but constrain it: "Only use questions," "No dialogue, only stage directions," "Every line must rhyme"

## The Repetition Piece

* "Generate a 1-minute scene where one phrase appears exactly 7 times in different contexts"

* Or: "Write a duologue where the same sentence is repeated, but its meaning shifts each time"

# Experiment with 

## Tokens
This can help you investigate differences in what is generated before more user input is required 
Or
You can use this is a constraint to see whether you can generate enough material for a whole performance using a small amount of tokens (economy of language!)

## Temperature
Run the same prompt at different "temperature" settings (low = predictable, high = chaotic). How does this affect the output? Can you combine different temperatures into one performance?

## Models 
Compare models if you are able

# Using Non Local Models 

If you have access to a model that runs in the cloud through a mode traditional interface you can use this if you want. 

If you are generating in real time during performance, you might need to use that services API for example to get it to work programmatically.
