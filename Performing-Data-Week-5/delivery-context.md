# Unit 

Performing Data is a 20 credit unit in Term 3 of MSc Applied Machine Learning for Creatives. This unit explores the integration of data within live performances and art installations, focusing on adaptive and interactive creative applications. Students will address realtime data processing techniques, enabling responsive and adaptable interactions within artistic contexts. The unit also introduces the application of generative AI in creative  practice, allowing students to explore AI-driven processes  within live performance and artistic practice. Students will study various data collection strategies, learning how to gather and incorporate live data for performance. 

# Learning Outcomes of Unit 

* **LO1** Build systems that enhance creative practices through data insights or machine learning (Knowledge, Realisation)
* **LO2** Analyse audience engagement data to adapt performances interactively (Realisation, Process)
* **LO3** Critically assess the technical, artistic, and ethical aspects of using data in creative settings (Enquiry)

# Learning Outcomes of the Class

* Understand and use the parameters of Stable Diffusion (strength, steps, guidance, resolution, seed, prompt) for real-time performance (LO1)

* Build an interactive img2img system that maps live inputs (webcam, mouse, keyboard, audio) to generation parameters (LO1)

* Evaluate the trade-offs between latency, frame rate and image quality, and choose settings to suit a performance context (LO1, LO3)

* Critically reflect on agency and authorship when performing with a generative model (LO3)
