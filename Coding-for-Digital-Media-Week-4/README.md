## Unit 

This unit provides an introduction to programming for digital media, focusing on its applications within creative fields. It covers key frameworks and tools that support digital media development, equipping students with practical skills for multimedia creation and analysis. Essential concepts include data representation and manipulation for images, audio, and video, enabling students to work creatively these media formats effectively. Additionally, students will explore real- time visualisation and sonification techniques, learning how to create responsive visual and auditory experiences central to interactive multimedia applications. This unit will also equip students with the theoretical background to think critically about the use of technology and AI in creative work and consider the power dynamics it supports and challenges. 


### Learning Outcomes of Unit 

* **LO1** Demonstrate computer programming skills in relation to creative industries contexts (Knowledge)

* **LO2** Demonstrate core mathematical skills required for performing computational operations on data (Enquiry)

* **LO3** Demonstrate knowledge of core algorithms and data structures for representing information relevant to creative industries contexts (Process, Realisation)

## Learning Outcomes of the Class

* Load, manipulate and rearrange audio files in Python using common List range indexing (LO1, LO3)

* Use array arithmetic functions to change perceptual characteristics and recombine audio in Python (LO2, LO3)

* Reflect on the use of analog and digital sampling as both a cultural and aesthetic choice (LO1)
